# Vérification mobile

Contrôle qualité d'une page ou d'un parcours sur téléphone.

1. Lance l'application en local.
2. Ouvre la page indiquée dans le navigateur à 375 px de large, puis 768 px, puis 1280 px.
3. Vérifie : pas de défilement horizontal, texte lisible, boutons ≥ 44 px, formules KaTeX non coupées, images légères.
4. Vérifie le focus clavier et le contraste des textes.
5. Liste les défauts trouvés avec une capture pour chacun, puis propose les corrections.
6. Corrige seulement après mon accord, puis refais les captures.
